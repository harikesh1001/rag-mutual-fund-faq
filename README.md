# Mutual Fund Facts

Foundation for a facts-only mutual fund FAQ assistant focused on SBI Mutual Fund schemes. The application is built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Getting Started

Install dependencies:

```bash
npm install
```

Copy `.env.example` to `.env.local` when environment configuration is needed:

```bash
cp .env.example .env.local
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run lint` runs ESLint.

RAG, embeddings, vector search, Gemini calls, Supabase integration, ingestion, authentication, and chatbot behavior are intentionally not implemented yet.
